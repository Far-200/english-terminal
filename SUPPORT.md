# Support

Use the Issues tab of the repository from which you obtained English Terminal to
contact its maintainers. If that repository has no issue tracker, contact the person
who supplied the source. No dedicated private security disclosure channel is currently configured.

Include the English Terminal version, Python version, operating system, the command
pattern, and a minimal reproducible example. Use public or synthetic repository
identifiers where possible. Never include `GITHUB_TOKEN` values, authorization
headers, credentials, or private repository listings. Do not post secret material
while reporting a suspected credential-handling issue.

For GitHub behavior and offline testing, see [the integration guide](docs/github-integration.md).
For support, open an issue in this repository or email [hello.farhaankhan@gmail.com](mailto:hello.farhaankhan@gmail.com).
